
# Project 7 – CI Validation for Terraform

![Terraform CI Validation](https://github.com/harshit-rarh/cp7/actions/workflows/terraform-ci.yml/badge.svg?branch=main)

## Project Overview

This project demonstrates Continuous Integration
(CI) for Terraform infrastructure code using GitHub Actions.

## CI Pipeline

The workflow automatically executes when code is pushed.

### Automated Checks

1. Terraform Format Check
2. Terraform Initialization
3. Terraform Validation

## Technologies Used

- Terraform
- Git
- GitHub
- GitHub Actions
- YAML

## Objective

Automate Infrastructure as Code validation
to maintain consistent and valid Terraform configurations.
